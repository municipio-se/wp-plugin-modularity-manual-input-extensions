# Changelog

## 1.0.1 — 2026-11-26

Expose each Manual Input row's saved link target while preserving the URL-only
link contract and stored metadata. The unused link text field is hidden only
for Manual Input; link titles remain intact when selecting internal pages.
Rendering the selected target requires compatible Municipio and Component
Library versions or the corresponding backports.

## 1.0.0 — 2026-09-17

First stable release with independent semantic versioning.

ACF Link editing, read-time normalization of legacy arrays, write-time
normalization of URL strings for ACF, and suppression of numeric legacy icons
outside the box layout.

The runtime behavior is preserved from the reviewed development baseline; this
preparation aligns release metadata and documents the release contract.
Reference acceptance and published Composer distribution were verified before
consumer adoption.

Documentation status corrected after publication. The immutable 1.0.0 archive
retains the original candidate wording; runtime code and the tag are unchanged.
